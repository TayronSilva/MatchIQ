# MatchIQ

> AI Career Agent que analisa currículos, compara com vagas de emprego e gera feedback inteligente para ajudar desenvolvedores a evoluírem profissionalmente.

---

## 📖 Sobre o projeto

O MatchIQ é um projeto desenvolvido para resolver um problema comum de quem procura oportunidades na área de tecnologia:

> "Meu currículo realmente atende aos requisitos desta vaga?"

Em vez de comparar apenas palavras-chave, o MatchIQ utiliza Inteligência Artificial e busca semântica para analisar o currículo do candidato, compreender seus conhecimentos e compará-los com as exigências das vagas.

Ao final da análise, o sistema apresenta um relatório completo contendo:

- Compatibilidade com a vaga
- Principais pontos fortes
- Competências ausentes
- Sugestões de melhorias no currículo
- Plano de estudos personalizado

---

## 🎯 Objetivo

Criar uma plataforma capaz de funcionar como um assistente de carreira baseado em IA, oferecendo análises técnicas que normalmente seriam realizadas por um recrutador ou Tech Lead.

---

## ✨ Funcionalidades

- Upload de currículo (PDF/DOCX)
- Extração inteligente de informações
- Identificação de competências técnicas
- Busca automática de vagas
- Matching utilizando IA
- Análise de lacunas (Gap Analysis)
- Ranking de compatibilidade
- Recomendações para evolução profissional
- Dashboard com métricas
